# 🚲 Bike Sales Analysis Dashboard

## 📌 Project Overview

This project is an interactive Bike Sales Analysis Dashboard developed using Microsoft Excel. The project focuses on analyzing customer data to understand bike purchasing behavior and identify patterns across income, gender, age, commute distance, marital status, region, and education.

The project follows a complete data analysis workflow, starting from organizing the customer dataset and preparing the data for analysis, followed by data exploration, segmentation, analysis, visualization, and dashboard development.

## 🎯 Project Objectives

- Analyze customer bike purchasing behavior
- Understand the factors associated with bike purchases
- Compare purchasing behavior across different customer segments
- Analyze income differences between bike purchasers and non-purchasers
- Examine purchasing patterns across different age groups
- Analyze the relationship between commute distance and bike purchases
- Explore customer characteristics such as gender, education, region, and marital status
- Build an interactive dashboard to present the analysis clearly

## 🔄 Data Analysis Process

### 1. Data Preparation

The customer dataset was organized and prepared for analysis to ensure that the information could be effectively analyzed and visualized.

### 2. Data Exploration

Different customer attributes were explored to understand the distribution of customers and their purchasing behavior.

### 3. Customer Segmentation

Customers were analyzed based on multiple attributes, including:

- Gender
- Age Bracket
- Marital Status
- Region
- Education
- Commute Distance
- Bike Purchase Status
- Income

### 4. Data Analysis

The data was analyzed to identify patterns and differences in bike purchasing behavior across various customer segments.

The analysis includes:

- Average income comparison
- Gender-wise purchase analysis
- Age-bracket analysis
- Commute-distance analysis
- Purchased vs. non-purchased customer comparison
- Demographic segmentation

### 5. Data Visualization

The analysis results were transformed into visual representations to make patterns and comparisons easier to understand.

### 6. Interactive Dashboard

An interactive dashboard was created to bring the analysis together in one place. Slicers allow users to filter the data and explore different customer segments dynamically.

## 📊 Dashboard Components

### 💰 Average Income Analysis

Compares the average income of customers based on gender and whether they purchased a bike.

### 👥 Customer Age Analysis

Analyzes bike purchasing behavior across different age brackets.

### 🛣️ Commute Distance Analysis

Examines purchasing behavior across different commute-distance categories.

### 🎓 Customer Demographic Analysis

Allows customer segments to be explored based on education, region, marital status, and other available attributes.
