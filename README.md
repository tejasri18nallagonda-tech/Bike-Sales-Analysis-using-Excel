# 🚲 Bike Sales Analysis Dashboard

## 📌 Project Overview

This project is an interactive Bike Sales Analysis Dashboard developed using Microsoft Excel.

The dashboard analyzes customer purchasing behavior based on income, gender, age brackets, commute distance, marital status, region, and education.

Pivot Tables, Pivot Charts, and interactive slicers were used to analyze and visualize the data.

## 🎯 Objectives

- Analyze bike purchasing behavior among customers
- Compare average income based on gender and bike purchase status
- Analyze bike purchases across different age brackets
- Understand purchasing patterns based on commute distance
- Explore customer segments using interactive filters
- Present the analysis through an interactive Excel dashboard

## 🛠️ Tools & Techniques

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Analysis
- Data Visualization

## 📊 Dashboard Analysis

### Average Income per Purchase

Analyzes the average income of customers based on gender and whether they purchased a bike.

### Customer Age Brackets

Shows bike purchasing patterns across different customer age groups.

### Commute Distance

Analyzes bike purchasing behavior across different commute-distance categories.

### Customer Segmentation

The dashboard can be filtered using:

- Marital Status
- Region
- Education
- Gender
- Purchased Bike

## 🔍 Key Insights

The dashboard helps identify patterns in bike purchasing behavior across different customer demographics, income levels, age groups, and commute distances.

Interactive slicers allow users to explore the data across different customer segments.
